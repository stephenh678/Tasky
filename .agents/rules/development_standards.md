# Tasky Engineering & Design Best Practices

## Guidelines for Changes and Edits:
1. **Interpret Intent ("What" and "Why"):** Deconstruct user requests to understand the root goal and workflow rather than applying surface-level code changes.
2. **Industry Standards:** Implement proven design patterns from leading productivity tools (Notion, Linear, Slack, Apple Notes, Obsidian).
3. **Comprehensive Coverage:** When implementing an interaction (open/close/remove/drag-and-drop/context menus), apply it consistently across all media (files, images, links, tables, checklists).
4. **Lifecycle & Disk Cleanup:** Ensure all added files are sandboxed in dedicated task folders and cleaned up cleanly on deletion.
5. **Quality & Verification:** Maintain 0 warnings, 0 errors, and clean builds at all times.
